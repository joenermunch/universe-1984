# ADR-0001: Record architecture decisions

- **Status:** Accepted (2026-11-08)
- **Context:** Decisions in a reconstruction need their evidence attached, or later contributors cannot tell historical constraints from taste.
- **Decision:** Every significant technical or fidelity decision is an ADR in `docs/decisions/`, numbered, with Context / Decision / Evidence / Consequences. ADRs cite source IDs from `docs/references.md` and evidence IDs from the evidence matrix.
- **Consequences:** Small overhead per decision; reviewers can audit fidelity.
